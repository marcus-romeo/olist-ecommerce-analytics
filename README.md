Olist E-Commerce Analytics

🚧 Project Status: In Progress

An end-to-end e-commerce analytics project using the Olist Brazilian e-commerce dataset.

The goal is to understand customer purchasing behavior and explore whether historical data can help predict future purchases.

What's Been Done
✅ SQL data preparation and analysis
✅ Customer-level modeling dataset
✅ 90-day repeat-purchase prediction target
✅ Logistic regression baseline
✅ Model evaluation
🔄 Random Forest model
⬜ Additional features and prediction horizons
⬜ Visualization and dashboard
⬜ Final findings and recommendations
Tools
